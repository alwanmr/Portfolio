## Featured Project

### [01. Housing Value Prediction with Regularized Regression](./01-housing-value-regression/)

**Regression · Ridge & LASSO · Feature Selection · Model Evaluation**

An experimental study of housing-value prediction using Ridge, LASSO, and Multiple Linear Regression. The project examines whether feature selection and treatment of an apparent upper boundary in the target affect predictive performance.

**Key questions**
- Does removing a highly correlated feature improve prediction?
- How does excluding observations at the apparent target boundary affect model performance and target coverage?
- Does regularization provide a meaningful advantage over ordinary multiple linear regression?
